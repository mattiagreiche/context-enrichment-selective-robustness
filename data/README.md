# Released probability data

`paper_calls.csv` has one row for each of the 800 fresh Responses API calls in the paper: 2 models × 2 worlds × 5 contexts × 4 surfaces × 10 calls. Each cell has five rows labeled `initial` and five labeled `extension`. It includes the frozen prompt hash, the returned `TRANSFER` and `RETAIN` branch masses, unreturned probability mass, censoring status, lower and upper conditional transfer-probability estimates, and the midpoint used in the paper.

The first output token's returned candidates were `TRANSFER` and/or `RE`, where `RE` begins `RETAIN`. Both branches were returned in 461 calls. In 339 calls one branch was absent from the returned candidates. For a censored call with reported transfer mass `t`, retain mass `r`, and unreturned mass `u`, the released lower and upper estimates are `t/(t+r+u)` and `(t+u)/(t+r+u)`; the analyzed value is their midpoint. Complete calls use `t/(t+r)` as both endpoints. This follows the recorded numerical repair convention applied to the provider log-probabilities.

`paper_results.json` preserves the original 10,000-resample percentile intervals, the reported surface-sensitivity and world-response measures, and the censoring sensitivity ranges. `analysis/reproduce.py` verifies the 800-row factorial structure, the prompt hashes, the probability arithmetic, and all published point estimates. It also performs a new within-cell bootstrap. `analysis/censoring.py` verifies the exact missing-branch sensitivity ranges. The original bootstrap seed was not saved, so its interval endpoints can vary by Monte Carlo error.

The CSV is derived from the four original run summaries; their SHA-256 hashes are recorded in `paper_results.json`. Raw provider responses, request metadata, call ledgers, usage, and timestamps are not released. The original runs omitted `top_p`; saved provider responses reported `top_p=0.98`. The reported estimates are conditional first-action-branch quantities, not full-string response probabilities. A sensitivity analysis over the censored-call bounds changed aggregate measures by at most 0.49 percentage points and preserved the context rankings within each model.
